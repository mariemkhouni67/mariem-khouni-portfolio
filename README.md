# Mariem Khouni -- Developer Portfolio Website

A modern, production-ready developer portfolio website engineered with **React**, **TypeScript**, **Tailwind CSS**, and **Three.js**.

## 🚀 Features

- **Futuristic 3D Digital Ecosystem**: Interactive Three.js canvas featuring floating orbital nodes, constellation particle systems, and dampened mouse parallax, optimized with `IntersectionObserver` and `prefers-reduced-motion` detection.
- **Glassmorphic & Futuristic Aesthetics**: Tailored palette (`#050816`, `#0B1120`, `#6366F1`, `#06B6D4`) with subtle glows, grid patterns, and accessible typography.
- **Dark / Light Mode**: Seamless theme switching with localStorage persistence.
- **Showcase Projects**:
  - **StudyMate**: Full-stack AI study platform (DeepSeek, ChromaDB, BGE-M3 RAG pipeline, Docker, MySQL, gamified learning).
  - **TravelScape**: Full-stack MERN travel booking platform with 3D hero, glassmorphism, Leaflet maps, multilingual bot, and admin CRUD.
  - **Decathlon Posture Coach**: AI-powered fitness app leveraging DeepSeek R1 reasoning across 873+ exercises matched with Decathlon products.
- **Detailed Project Modal**: Clean architectural breakdowns, problem-solution statements, and technical takeaways strictly adhering to verified project details.
- **Printable / Downloadable CV Modal**: Complete resume ready for 1-click printing or PDF export.
- **Responsive Navigation & Mobile Drawer**: Sticky blurred header with active section tracking and smooth scrolling.
- **Direct Contact System**: Form with mailto pre-filling and instant one-click clipboard copy for `mariem.khouni@outlook.com`.
- **Zero Hallucination Guarantee**: Contains only verified experience, technologies, and achievements.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js
- **Icons**: Lucide React + custom SVG brand icons

## 💻 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Preview

```bash
# Build production bundle with optimized code-splitting
npm run build

# Preview production build locally
npm run preview
```
